# Tourist Management System

A Java-based Tourist Management System developed using Java Swing and MySQL. This project helps manage customer bookings, hotel reservations, tour packages, and travel details efficiently.

---

## 🚀 Features

- User Login & Signup
- Customer Management
- Tour Package Booking
- Hotel Booking
- View Tour Details
- Payment Details
- Admin Dashboard
- MySQL Database Connectivity
- Simple and User-Friendly GUI

---

## 🛠️ Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
